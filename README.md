# site-cicd

![Deploy static site](https://github.com/gurynych/site-cicd/actions/workflows/deploy.yml/badge.svg)

Учебный статический сайт с автоматическим развёртыванием через GitHub Actions.

Перед публикацией workflow проверяет разметку index.html с помощью html-validate. Если в разметке есть ошибки, сайт не публикуется.

Сайт на GitHub Pages: https://gurynych.github.io/site-cicd/

Сайт на Vercel: https://site-cicd-plum.vercel.app/
